# Обзор

## Что за приложение

Gonna Play помогает людям находить любительские футбольные матчи и записываться на них. Организатор создаёт матч на площадке в конкретное время с форматом (пять на пять, семь на семь, одиннадцать на одиннадцать) и лимитом игроков. Игроки записываются на свободные места, при заполнении попадают в лист ожидания. Перед игрой матч разбивается на две равные команды с учётом уровня и позиций игроков. Уведомления о напоминаниях, заполнении и разбивке уходят игрокам, в том числе через Telegram.

Рейтинг игрока — самооценка: игрок сам указывает уровень (junior, middle, senior, legend). Вычисляемого рейтинга и оценок после матча пока нет (см. [decisions.md](decisions.md)).

## Стек

Бэкенд собран на Fastify 5 в режиме ESM на TypeScript. Данные — PostgreSQL через Prisma 6. Схемы запросов и ответов описываются на TypeBox и подключаются через `@fastify/type-provider-typebox`. Вход — JWT (`fastify-jwt`) плюс Telegram. Логирование — pino. Документация API — `@fastify/swagger`, из её OpenAPI генерируется коллекция Postman. Медиа (фото площадок, аватары) хранятся в объектном хранилище, S3-совместимом, и отдаются через CDN.

Точные версии зависимостей всегда сверяй с `package.json` — он источник правды.

## Модули

Каждый ресурс — отдельная папка `src/<resource>/` со слоями controller → service → repository → model (см. [conventions.md](conventions.md)). Целевой состав модулей:

- `auth` — регистрация, вход по email и через Telegram, токены;
- `user` — учётные записи;
- `player` — игровые профили (уровень, позиция);
- `match` — матчи и запись участников;
- `team` — разбивка на команды;
- `notification` — уведомления и каналы доставки;
- `venue` — площадки и их фотографии;
- `storage` — обёртка над объектным хранилищем (presigned-загрузка).

Плюс сквозные плагины: авторизация, версионирование по User-Agent, feature flags, обработчик ошибок, swagger, rate-limit, prisma. Фоновые задачи (напоминания, лист ожидания) — на `node-cron`.
